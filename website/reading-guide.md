## 建议阅读顺序

1. **编程选型篇**：全流程总览 → 评测 → 编程工具与 Agent 横评 → 协作工作流 → Coding Plan / 中转 / 聚合 → 省钱与 Token 治理 → 开发环境、增强工具与卸载清理。
2. **Agent 构建篇**：Prompt → Skills → MCP → Hooks → Subagents。
3. **项目实践篇**：Cursor / Codex / Kiro → WSL → 办公与设计原型 → Claude Code 实践与开发笔记 → 绘图与 Stitch × Figma × MCP。
4. **学习资源篇**：学习路线、社区资源、教程速查与 GitHub 周边。按需查阅，不必按序通读。
5. **应用选型篇**：办公桌面 Agent、对话工具、智能体平台、绘图与视频、OpenClaw 生态与开发周边。
