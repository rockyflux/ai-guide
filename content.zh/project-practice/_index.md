## 项目实践

本栏目主要收录各类基于 AI 工具的**真实项目实战案例**与**可落地 SOP**，重点回答三个问题：

1. 「**我应该从什么样的项目开始练手？**」  
2. 「**具体要怎么把任务拆给 AI？**」  
3. 「**做完一个项目之后，怎样沉淀成可复用模板？**」  

和「概念 / 方法论」不同，这里的文章都尽量围绕**一个个具体项目**展开：从最初的想法、需求文档，到建仓库、写代码、联调、上线、复盘，完整呈现「从 0 到 1 做完一个东西」的全过程。

### 栏目结构总览

目前「项目实践」将逐步覆盖以下几类内容：

- **端到端项目纪实**：  
  从零开始做完一个小项目的完整过程记录，包含中途的岔路、踩坑与回滚决策，尽量还原真实开发节奏。

- **项目级最佳实践**：  
  不再只讲「单次对话怎么问」，而是站在「一个完整项目周期」的视角，整理：需求拆解、协作模式、版本控制、回归验证等套路。

- **可复用项目模板 / SOP**：  
  把实践中打磨出来的「任务模版、工作流、检查清单」抽象出来，方便你在新项目中直接套用或二次改造。

- **典型场景项目合集（规划中）**：  
  围绕几个常见目标（如：自动化脚本、轻量 Web 应用、数据处理流水线、知识小工具等）给出针对性的项目方案与样例仓库。

随着内容的补充，栏目会逐步形成一条「**从第一个小项目 → 多项目经验复用**」的成长路径。

### 建议阅读顺序

如果你是**新手或刚开始用 AI 做项目**，可以按下面顺序来逛这个栏目：

1. **先看整体路线**  
   - 《新手端到端项目实战路径》  
     这一篇会把「从选模型 / 配环境，到做完第一个小项目」相关的文章串成一条完整路径，适合先通读一遍，心里有个地图。

2. **理解项目级最佳实践**  
   - 《项目实践：最佳实践与常见坑》（规划中）  
   - 《Everything Claude Code 总览》（从项目视角回看整套配置仓库的用法）  
   这一层更偏「打法」：如何用 Plan Mode、如何控制节奏、如何让 AI 主动帮你做验证与重构。

3. **跟着一个真实案例做一遍**  
   - 《项目实践：从一个具体案例开始》  
   - 《新手端到端项目实战路径》中的「完整纪实」部分  
   选一个你最感兴趣、规模适中的项目，照着文章边看边做，先完成「第一个闭环」比什么都重要。

4. **项目之后，沉淀为自己的 SOP**  
   - 梳理本次项目中的：需求模板、工作流步骤、验证清单，改写成适合你自己的版本；  
   - 后续可以把这些个人 SOP 存进自己的知识库 / 仓库，在新项目中反复复用。

### 已有与规划中的内容

为了方便你判断「现在这个栏目大概能看到什么」，这里简单列一下当前与规划中的内容类型（部分名称以实际文章为准）：

- **已完成 / 在编写中**  
  - 新手从 0 到 1 做完第一个小项目的完整纪实  
  - 基于 Claude Code / Cursor / OpenCode 的端到端协作示例  
  - 项目级工作流设计：如何组织「多轮对话 + 多 Agent + 多仓库」  

- **计划补充**  
  - 不同体量项目的拆解范式：脚本级 / 工具级 / 产品级  
  - 面向个人开发者与小团队的协作模式对比  
  - 项目失败 / 半途而废的反面案例分析：哪些坑可以提前避开

你可以把「项目实践」理解为：  
**这里不只是告诉你「AI 很强」，而是用一个个具体项目，带你一起练出一套「能稳定复用到下一个项目」的做事方法。**
