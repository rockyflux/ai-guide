## 项目实践与案例：把“会用工具”变成“能交付成果”

面向有经验开发者的目标很简单：**用 AI 把一个项目从 0 跑到可交付**，并把过程沉淀成你自己的 SOP。

本栏分两块：

- **开工包**：选定工具后，10 分钟级跑通 Cursor / Codex / Kiro  
- **交付闭环**：路线图 → 案例练手 → 最佳实践 / 配置集 → 需求到原型
