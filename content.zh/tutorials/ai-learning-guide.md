## 学习路径推荐

### 🚀 快速入门路径（2-4 周）

```
1. [DeepLearning.AI] ChatGPT Prompt Engineering（1小时）
2. [Microsoft] Generative AI for Beginners（选学 5 课）
3. [Anthropic] Prompt Engineering Tutorial（2小时）
4. 实践：调用 OpenAI/Claude API 完成一个小项目
```

### 📚 系统学习路径（3-6 个月）

```
1. [Coursera] 吴恩达 Machine Learning Specialization
2. [d2l.ai] 动手学深度学习
3. [Karpathy] nn-zero-to-hero → nanoGPT（手写到精简训练代码）
4. [rasbt / Datawhale] LLMs-from-scratch 或 Happy-LLM（从零实现 GPT）
5. [Stanford] CS224n 自然语言处理；进阶可选 CS336
6. [DeepLearning.AI] Deep Learning Specialization
7. [GitHub] LLM Course - 大模型专项
```

### 🎯工程实战路径（1-2 个月）

```
1. [OpenAI] Cookbook + API 文档
2. [DeepLearning.AI] LangChain 短课程
3. [DeepLearning.AI] RAG 检索增强
4. [GitHub] ai-engineering-from-scratch — 按阶段从原理做到可交付工件
5. [GitHub] ai-agent-book — Agent 原理到工程（选章跑实验）
6. [WalkingLab] Learn Harness Engineering — 给 Coding Agent 做规则、验证与跨会话交接
7. [GitHub] 选择一个开源项目贡献
```
