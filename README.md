## 这是什么

把 AI 从「会聊天」推进到「能稳定交付」的中文实践指南。内容按任务组织。

适合已有开发经验、想把 AI 编程、多 Agent 协作和项目级 SOP 落到真实仓库里的人。

## 本地开发

需要 **Node.js 22+**：

```bash
npm ci
npm run dev
```

默认地址由终端输出，路径前缀为 `/ai-guide/`。发布与检查见 [WEBSITE.md](https://github.com/rockyflux/ai-guide/blob/main/WEBSITE.md)。
