## 💻 本地开发

### 前置要求

- **Hugo Extended** 0.148.0+ （需要 Extended 版本支持 Dart Sass）
- **Git** 2.0+

### 快速启动

```bash
# 克隆仓库
git clone https://github.com/rockyflux/ai-guide.git
cd ai-guide

# 初始化子模块
git submodule update --init --recursive

# 启动本地服务器
hugo server
```

然后访问 `http://localhost:1313` 即可预览。
